## Proyekk Laravel FigureVault
<p>Ini adalah proyek laravel FigureVault</p>

## Fitur Utama

* Autentikasi Admin
* Manajemen Produk (CRUD)
- Manajemen Transaksi
- Dashboard
- Laporan Penjualan
- Export/Import (PDF & Excel)
- Market User (katalog produk)
- Profil Pengguna
- Riwayat Transaksi

## Teknologi yang Digunakan

•	Laravel 
•	MySQL 
•	HTML, CSS, dan JavaScript 
•	Tailwind CSS 
•	Maatwebsite Excel 
•	DomPDF
